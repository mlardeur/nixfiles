# AGENTS.md

Personal NixOS + Home Manager dotfiles managed as a single flake. System configs in `hosts/`, user configs in `home/`.

## Commands

```bash
# NixOS systems (requires sudo)
sudo nixos-rebuild switch --flake .#hera
sudo nixos-rebuild switch --flake .#athena

# Home Manager (standalone users)
home-manager switch --flake .#maxime@hera
home-manager switch --flake .#maxime@athena
home-manager switch --flake .#zion@zion

# Format (nixpkgs-fmt is the flake formatter)
nix fmt

# Update lockfile / inputs
nix flake update
```

There is no CI, test suite, or linter. Verification is `nix fmt` plus a dry-run `nix flake check` / a real `nixos-rebuild build --flake .#<host>`.

## Host / user matrix (`flake.nix`)

| Output | Type | pkgs channel | Home Manager |
|---|---|---|---|
| `nixosConfigurations.hera` | NixOS | unstable | `maxime@hera` |
| `nixosConfigurations.athena` | NixOS | unstable | `maxime@athena` |
| `zion@zion` | standalone HM (`targets.genericLinux`) | **stable 25.11** | release-25.11 |

Two nixpkgs channels coexist: `nixpkgs` (nixos-unstable) and `nixpkgs-stable` (25.11). Only `zion` uses stable. `pkgs-stable` is bound in `flake.nix`; `home-manager-stable` follows `nixpkgs-stable`.

`hosts/toolbx/mlardeur.nix` is a Fedora toolbox config that is **not wired into `flake.nix` outputs** — it is applied manually and uses build-time sops decryption. Do not assume editing it affects any flake target.

## Layout

- `hosts/<name>/configuration.nix` + `hardware-configuration.nix` — NixOS system. `hardware-configuration.nix` is generated by `nixos-generate-config`; do not edit by hand.
- `hosts/<name>/maxime.nix` — per-host Home Manager entrypoint; imports a subset of `home/`.
- `hosts/shared/` — imported by both NixOS hosts. `samba-mount.nix` defines a custom `mountSambaShares` option.
- `home/cli`, `home/desktop`, `home/programs/*` — reusable HM modules; each host opts into a subset.

## Secrets (sops-nix)

- `.sops.yaml` defines two age recipients (`hera`, `toolbx`); encrypted files live in `secrets/*.yaml` (regex `secrets/.*\.yaml$`).
- `home/cli/ssh.nix` points `sops.defaultSopsFile` at `secrets/ssh.yaml` and decrypts SSH keys to `~/.ssh/id_ed25519{,.pub}`.
- Age key location: `~/.config/sops/age/keys.txt` (not in repo). See `sops_toolbox_guide.md` for the toolbox manual-activation flow.
- Never commit plaintext secrets; `secrets/ssh.yaml` is encrypted and committed.

## Gotchas

- `system.stateVersion` differs per host (`athena` 23.05, `hera` 24.11, HM `maxime` 26.05, `zion` 24.11). Never bump these.
- `samba-mount.nix` mounts CIFS shares using a credentials file at `/etc/nixos/smb-nebula-secrets` that is not in this repo — mounting will fail without it.
- `home/cli/ssh.nix` works around Home Manager's SSH config by writing `~/.ssh/config_source` and copying it to `~/.ssh/config` (chmod 600) via `onChange`.
- `rebuild.log` is a leftover debug log committed by accident; ignore it.
- `home/desktop/eww/AGENTS.md` documents the (currently commented-out) eww `configDir`.
